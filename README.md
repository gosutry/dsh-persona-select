# dsh-persona-select
DSH注入系统提示词和设置注入上下文插件。 本文中和插件设置界面都将注入系统提示词的行为称作“人设正文”，将设置注入上下文的行为称作“历史对话”。

可通过在设置界面人设管理保存为预设“人设”，并且支持将保存的人设正文和历史对话作为数据块选择PNG图片或作为JSON文件导出，用PNG图片本身作为封面。注入的系统提示词可以自行编辑注入位置。支持屏蔽dsh本身注入的系统提示词、runtime上下文、schema工具以及其他user侧内容，使得发送内容保证让模型仅接收对话内容，且拥有工具保活通道，避免后续调用工具仅输出文本。历史对话可通过DSH本身导出(/export)的Session日志直接导入，用仿照DSH本身注入标签的格式包裹。各会话单独保存设置和人设，人设切换和设置勾选项不影响新会话和进行中的会话。
